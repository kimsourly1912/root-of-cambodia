Previous READMEs live under 2026-10/readmes with distinct names and original-path banners. Old docs-root filenames are listed above with their current authority; in-repository references point directly at canonical docs or snapshots.

Accepted scope, invariants, selected tooling and state-handoff rules were extracted before archival. Unselected technologies, old cost estimates, obsolete execution instructions and proposed-but-unimplemented APIs remain historical, not current release guidance. External historical research URLs are retained as evidence and are not fresh vendor/pricing verification.
